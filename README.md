# Spotify Clone

The Spotify Clone is a static music streaming website inspired by Spotify. It is created using HTML and CSS with images to design a Spotify-like interface.
---

Features
Spotify-inspired user interface
Sidebar navigation
Music cards
Playlist section
Music player design
Responsive design
Technologies Used
HTML
CSS
Images
Font Awesome
Google Fonts
